# ترازینو | Tarazino — نسخهٔ ۰٫۶٫۰

تغییرات بازطراحی، ورود با رمز/اثر انگشت و فایل‌های تغییرکرده: `docs/CHANGELOG.md`.

اپ اندروید مدیریت مالی فارسی. **این مرحله فقط بخشی از پروژه است**؛ هنوز اپ کامل نیست.

## در این بسته هست
- هستهٔ مالی قطعی بدون AI (`domain/Ledger.kt`): موجودی از موجودی اولیه + تراکنش‌ها، انتقال داخلی، جلوگیری از ثبت/کسر دوباره، چک آینده، طلب/بدهی.
- ماشین‌حساب وام‌های ایران با ۴ روش و کاتالوگ پیش‌فرض (`LoanCatalog`, `docs/IRAN_LOANS.md`).
- تقویم شمسی، ارقام فارسی/عربی/لاتین، تبدیل مبلغ نوشتاری و پیش‌نویس تراکنش از متن (همیشه نیازمند تأیید).
- تنظیمات AI: ورود کلید API برای DeepSeek/OpenAI/Claude/Grok/سازگار با OpenAI، رمزنگاری با Android Keystore، آدرس و مدل قابل ویرایش، آزمون اتصال.
- اسکلت Room با ایندکس یکتا برای کلید idempotency و قسط وام.
- ۴ فایل تست JUnit (اجرا نشده؛ `docs/TEST_REPORT.md`).

## امکانات این نسخه (همه نوشته شده، هیچ‌کدام هنوز کامپایل/اجرا نشده)
داشبورد، حساب‌ها، تراکنش‌ها (ثبت دستی، ثبت با جملهٔ فارسی با پیش‌نمایش و تأیید، ویرایش، حذف، فیلتر)، بودجه با هشدار، اهداف پس‌انداز (اختصاص بدون تغییر موجودی)، وام‌ها (ثبت، جدول اقساط، پرداخت تک‌باره، مانده)، ماشین‌حساب وام‌های ایران، چک/طلب/بدهی بدون اثر بر موجودی تا تسویه واقعی، گزارش و نمودار (دایره‌ای، ستونی، روند، مقایسه، ۱/۳/۶/۱۲ ماه، پیش‌بینی مشروط)، دستیار AI با کلید خودت، اعلان‌های محلی (WorkManager)، تم روشن/تاریک/سیستم، خروجی CSV، حذف داده.

## ساخت با GitHub (روش پیشنهادی)
1. پوشهٔ پروژه را در یک مخزن **خصوصی** GitHub بریز (`.github/workflows/android.yml` همراه آن است).
2. تب Actions ← Android CI. بعد از اتمام، APK دیباگ در Artifacts (`Tarazino-debug-apk`) است.
3. اگر build قرمز شد (محتمل است)، متن خطای لاگ را برایم بفرست تا اصلاح کنم (کد هنوز هیچ‌وقت کامپایل نشده).
4. هرگز کلید API یا keystore را commit نکن؛ کلید AI را فقط داخل خود اپ وارد کن.

## اجرا محلی
1. Android Studio جدید + JDK 17 را نصب کن و پوشهٔ پروژه را باز کن (Gradle wrapper را خودش می‌سازد؛ یا `gradle wrapper --gradle-version 8.9`).
2. نسخه‌های وابستگی (AGP 8.7.3، Kotlin 2.0.21، Compose BOM 2024.12.01، Room 2.6.1) از حافظه نوشته شده‌اند؛ اگر Sync خطا داد به نسخهٔ جدیدتر ارتقا بده.
3. `./gradlew :app:testDebugUnitTest` و سپس `./gradlew :app:assembleDebug` (خروجی: `app/build/outputs/apk/debug/`).
4. تب «هوش مصنوعی» ← ارائه‌دهنده را انتخاب، آدرس و نام مدل را از مستندات رسمی همان سرویس وارد، کلید را ذخیره و «آزمون اتصال» را بزن. هزینهٔ API جداست.

## استفادهٔ شخصی (بدون بک‌اند)
دستیار آفلاین بدون کلید کار می‌کند. برای هوش مصنوعی واقعی رایگان: در openrouter.ai حساب بساز، از بخش Keys یک کلید بگیر، در اپ «بیشتر ← هوش مصنوعی» ارائه‌دهندهٔ OpenRouter (پیش‌فرض) را بگذار، کلید را ذخیره کن و دستیار را روشن کن. سقف مدل‌های `:free` طبق مستندات OpenRouter ۲۰ درخواست در دقیقه و ۵۰ در روز (تا قبل از خرید اعتبار) است. دسترسی از ایران بررسی نشده؛ Gemini در فهرست رسمی کشورهای پشتیبانی‌شده ایران را ندارد.
