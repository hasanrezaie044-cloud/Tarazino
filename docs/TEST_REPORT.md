# گزارش آزمون — مرحلهٔ ۱ (۱۴۰۵/۰۸/۰۲)

## واقعاً اجرا شد
- **مرجع Python برای تقویم شمسی:** ۱۰ تاریخ مرجع (نوروز ۱۳۹۸ تا ۱۴۰۵، ۱۴۰۳/۱۲/۳۰، ۱۴۰۵/۰۸/۰۲) همه تطبیق داشتند و رفت‌وبرگشت ۷۰٬۰۰۰ روز بدون خطا بود. (نسخهٔ اول با الگوریتم jalaali-js که از حافظه نوشتم خراب بود و دور ریخته شد؛ نسخهٔ نهایی قاعدهٔ ۳۳ ساله است.)
- **مرجع Python برای مبلغ‌های نوشتاری:** ۸ نمونه (۳۵۰ هزار، سه و نیم میلیون، …) درست.
- **مرجع Python برای وام:** مقادیر اقساط مساوی، سود ساده و جریمه که در `LoanTest` ثابت شده‌اند از اینجا آمده‌اند.

## اجرا **نشد**
- کامپایل Kotlin و اجرای تست‌های JUnit در `app/src/test`: در محیط من kotlinc، Gradle و شبکه (دانلود وابستگی) نبود. تست‌ها نوشته شده‌اند ولی **نتیجهٔ قبول/رد ندارند** و کد ممکن است خطای کامپایل جزئی داشته باشد.
- ساخت APK، اجرای UI، تست‌های Room/دستگاه، نسخهٔ وابستگی‌ها (از حافظه نوشته شده‌اند، بررسی آنلاین نشد).
- اتصال به DeepSeek/OpenAI/Claude/Grok (کلید و شبکه نبود). بک‌اند هنوز نوشته نشده (مرحلهٔ ۴).

## مرحلهٔ ۲
کد صفحه‌ها، ViewModel و Repository نوشته شد؛ هیچ‌کدام کامپایل یا اجرا نشده. تست‌های جدید: `Today.parseJalali` و مرز روز تهران (اجرا نشده).

## مراحل ۳ و ۴
صفحه‌ها، گزارش‌ها، اعلان‌ها، دستیار، بک‌اند و مستندات نوشته شدند؛ فقط `ReportsTest` (آمار ماهانه، روند، پیش‌بینی، `plusMonths`) افزوده شد و اجرا نشده. برای بک‌اند هیچ آزمونی نوشته/اجرا نشد. قیمت DeepSeek از صفحهٔ رسمی در ۲۰۲۶-۱۰-۲۵ خوانده شد؛ نام مدل پیش‌فرض به `deepseek-flash` اصلاح شد (نام قبلی من منسوخ بود).

## نسخهٔ ۰٫۴
بازطراحی کامل UI، ورود و تصاویر نوشته شد. نخستین build (پیش از این نسخه) فقط یک خطای import داشت که رفع شد؛ کدهای جدید هنوز کامپایل نشده‌اند. پردازش تصاویر با Python/Pillow انجام و خروجی آیکون با پیش‌نمایش دیده شد؛ ظاهر روی گوشی بررسی نشده. هیچ آزمون واحد جدیدی برای ورود/رابط نوشته نشد.
